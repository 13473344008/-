# 批次二维码预览与下载

批次详情的“数字身份证预览与稳定链接”区域新增“预览 / 下载二维码”。存在已发布版本且稳定 URL 有效时可用；未发布时提示先发布。

- 弹窗显示批次编码、完整稳定链接、二维码预览。
- PNG 为 1024 × 1024，SVG 为矢量格式。两者黑白配色、四模块留白、M 级纠错，无覆盖图案。
- 编码内容使用现有稳定 URL，排除历史版本路径、查询参数及片段；语言切换不改变二维码。
- 测试记录、本地模式显示测试提醒。文件名使用批次编码。
- 浏览器本地生成，不上传到第三方二维码平台，不涉及数据库迁移。
- 切换批次清除旧结果，下载过程中生成失败可重新打开重试。

本地验证：前端 43 个测试文件、334 项测试通过；新增 PNG 解码核对完整 URL、无效目标拦截、发布前禁用、切换批次清理测试。
