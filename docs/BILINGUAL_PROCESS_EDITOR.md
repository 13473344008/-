# 中英文工艺编辑

产品模板中的工艺步骤直接填写中文与英文名称，新增时自动分配唯一 STEP 编号，不显示内部代码输入框。旧代码不改名；单次编辑期间删除步骤后不会复用其代码。两个语言字段均允许留空，不自动翻译，不把两种语言变为必填。

模板更新请求可携带 process_labels，步骤和名称在同一事务内保存，仍检查原有乐观锁和草稿权限。删除步骤时同步删除其工作翻译标签，已封版或已发布数据不修改。名称变化使对应翻译回到草稿；新建语言行先沿用源产品名称作为未批准草稿，界面提示核对后再批准。

管理界面原本已有中英文；业务模板、自定义模块、内部预览及公开站点语言入口现在只提供中英文。其他语言历史数据和旧发布格式保持可读，不删除存量语言或收紧旧发布 JSON schema。新增产品源语言、产品翻译写入和模块翻译入口只允许中英文。

测试包含自动代码冲突避免、中文重复名称、数据库原子保存、过期版本拒绝、非法标签不产生部分提交、删除步骤保持其余名称关联。服务器更新需备份当前数据库和部署环境，仅更新测试管理项目，保留性能配置挂载，禁止重启共享 Caddy、Directus 和旧公开项目。公开测试服务尚未上线时不替换旧公开 POC 的静态目录。
