## 2. Editor亲手创建一条新数据（约10分钟）

用Editor登录，在产品模板页新建产品，建议编码`MANUAL-20260911`、名称“人工验收产品”。重做时换新编码，避免重复编码冲突。

- [ ] 维护R1：确认源语言名称，填写25kg等包装字段并保存；勾选源语言文字已确认并保存翻译。
- [ ] 主图区域填图片标签，显式勾选公开意图，上传一张自己的PNG/JPEG；查看预览、大小、Hash、MIME、尺寸。
- [ ] 新增`asset_gallery`模块（key建议`manual_gallery`），填写标题/说明，状态设为就绪，勾选文字已确认及模块公开意图，保存。
- [ ] 在gallery图片面板填写标签、勾选图片公开意图，上传另一张PNG/JPEG。
- [ ] 封版前试一次解除图片关联再重新上传；结果可见，页面不应报不可恢复错误。
- [ ] Seal R1并设置默认版本；封版后图片和内容编辑应被禁止。

图片限制：PNG/JPEG、最多2MiB、边长最多4096、像素最多1600万；主图1张、gallery最多16张。主图已有关联时须先解除再上传。SVG/PDF等不在本轮支持范围。模块公开意图与图片公开意图是两层控制；没有明确公开的图片不能进入公开候选。

如提交提示缺少日期、公开模块未就绪或源文字未确认，应修正明确提示后重试。这些校验是预期行为。不要为了通过而绕过提示。

- [ ] Editor退出，Reviewer登录；在审核队列打开刚提交的批次，查看冻结预览，确认图片可见。
- [ ] 填写具体原因后Reject，批次返回Draft；历史中保留原因。
- [ ] Reviewer退出，Editor登录；按原因修改内容，保存并重新Submit。
- [ ] Reviewer再次登录并Approve；状态为Ready for Publish。
- [ ] 审核历史保留两次提交，批准本身不应生成公开版本。
- [ ] Reviewer不能直接改图片或执行发布；Editor不能批准自己的提交。
