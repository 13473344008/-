## 统计口径与限制

读取本项目私有Nginx combined access log，只统计合法 `/b/{code}` 或 `/b/{code}/v/{n}` 的GET 200/304，图片/JSON/CSS请求及失败页面不计入。扫码、点击、刷新和自动测试无法可靠区分，因此名称为“页面访问”，不是人数或确定扫码次数。当前本地记录包括自动测试访问。

目前是当前保留日志的读取视图，不是跨轮转的永久分析数据库。最多读取文件最近16MiB，截断时页面明确告知；不存在或不可读取时显示不可用，而非虚构0次。所选90天不代表日志一定保存了90天。正式部署前需要配置日志留存/轮转、跨归档统计和备份策略；本次未设置全局清理或自动删除。

访问者IP仅用于服务端离线地区解析，不建立访客身份表。基础设施原有的Nginx原始访问日志仍含IP，位于私有日志目录；“界面只记录地区”不等于底层原始日志已做IP脱敏。公开页未加Cookie、跟踪脚本或Admin API请求，统计服务停止不影响静态浏览。

地区为IP大致归属地，不是GPS，也不能证明某人在某城市。本机/内网显示“本机 / 内网”，没有配置地区库或无法定位时显示未知。统计读取时使用当前地区库解析；后台登录/操作地区在写日志时记录。时间保存为UTC或原系统时间，访问界面转换为浏览器时区。

## 配置及实现

后端新增 `GET /api/v1/passport-traffic`，JWT→LiveIdentity→Casbin→数据权限，复用Product范围限制可见Batch；无权限范围时不泄露批次。仅服务端固定配置文件路径，客户端不能指定任意日志文件。

环境变量：

- `PASSPORT_ACCESS_LOG`：本项目私有Nginx combined日志的绝对路径。
- `PASSPORT_GEOIP_V4` / `PASSPORT_GEOIP_V6`：离线地区库绝对路径。
- `PASSPORT_TRUSTED_PROXIES`：明确允许的代理CIDR列表；空值默认不信任X-Forwarded-For。只有直接连接来自可信代理时才从右侧逐跳取首个不可信客户端IP，不能相信客户端自填头。

离线实现使用[ip2region官方Go查询器](https://github.com/lionsoul2014/ip2region/tree/master/binding/golang/xdb)及其地区库。Go模块代理下载超时后保留了原始上游源码和Apache许可至`admin/go-admin/internal/ip2region/`，没有自创数据库格式。地区库在人工runtime的geo目录，下载URL、大小、SHA在geo/sources.json；不在公开根，不把IP发给第三方查询API。国家/省/城市三段展示，不展示运营商。

## 人工复验

1. 刷新首页，确认无销售/支付/运营卡片，已有本机访问显示地区而非访客姓名。
2. 打开一次公开批次页，回首页点搜索，核对访问量和最新记录增加；单独刷新图片不应增加。
3. 过滤一个批次、切换期间，核对明细与地区分布。
4. 用Admin登录，从首页打开登录日志和操作日志，查看刚才账号、时间、IP及“本机 / 内网”。
5. 原T12人工业务链继续在同一个副本操作。公网地区和生产日志留存需等后续明确授权部署后验证。
