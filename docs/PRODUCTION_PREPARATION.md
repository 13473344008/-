## 已修复

1. 测试记录编码必须含独立 TEST 段，后端在 CreateBatch、CloneBatch、Readiness/Submit 和发布分配版本前统一校验。默认 record_type=test 也受到校验；商业记录不强制 TEST。保留历史编码和冻结审核数据，不用 SQL 改客户批次。
2. 管理端新建/复制对话框增加规则说明、实时字段错误和按钮禁用，提交处理也验证，覆盖回车提交；前后端均 trim/转大写后检查独立 TEST 段，CONTEST/TESTING 不能混过。
3. 历史已批准的不合规测试记录在发布前得到明确可操作错误，不再分配新发布版本后才出现笼统 schema 错误。
4. 修正部署构建：必须带 `sqlite3,t4_schema`，否则只初始化框架迁移，漏掉身份证表。没有修改已执行过的历史迁移。说明和 Docker 构建命令同步修正。
5. 登录页不再预填框架演示密码；部署初始化只接受全新库，随机初始密码与 JWT 独立存放，拒绝重复 bootstrap 重置已有管理员。

公开页面移除发布信息、系统更名和访问日志需求的此前修改均保留。二维码下载仍不在本轮范围内；稳定 URL 功能保留。
